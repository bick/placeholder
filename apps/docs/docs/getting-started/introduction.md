# Introduction

Welcome to **PlaceholderJS** - ridiculously simple and lightweight placeholders for your projects.

## What is PlaceholderJS?

PlaceholderJS is a free placeholder service designed for developers that generates placeholder images on-demand. It integrates seamlessly with React & NextJS and can also be used via CDN for any project.

## Key Features

- 🚀 **Lightweight**: Minimal bundle size with no dependencies
- 🎨 **Customizable**: Control text, colors, and sizing
- 📱 **Responsive**: Works with any dimensions up to 4000x4000
- ⚡ **Fast**: Generates SVG images on-demand
- 🛠️ **TypeScript**: Full TypeScript support for React components
- 🌐 **Universal**: Use via CDN or as a React component

## How It Works

PlaceholderJS generates SVG-based placeholder images either through:

1. **CDN URLs** - Direct image URLs for HTML, CSS, or any framework
2. **React Component** - A React component with props for seamless integration

All images are generated server-side and cached for optimal performance.

## Use Cases

### 🎨 **Prototyping**
Quickly mock up layouts without worrying about placeholder content.

### 🧪 **Testing**
Generate consistent placeholder images for development and testing.

### ⏳ **Loading States**
Show placeholders while real content loads.

### 📐 **Design Systems**
Maintain consistent placeholder styling across your projects.
