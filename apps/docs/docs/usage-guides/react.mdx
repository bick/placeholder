# React Usage

import { Placeholder } from 'placeholder';

Use PlaceholderJS as a React component with full TypeScript support and seamless integration into your React applications.

## Installation

First, install the package:

```bash
npm install placeholder
```

## Basic Import

```jsx
import { Placeholder } from 'placeholder';
```

## Basic Usage

### Required Props

Width and height are required:

```jsx
<Placeholder width="300" height="200" />
```

**Result:**

<Placeholder width="300" height="200" />

## Text Prop

Add custom text to your placeholder:

```jsx
<Placeholder width="400" height="250" text="Hello React!" />
```

**Result:**

<Placeholder width="400" height="250" text="Hello React!" />

### Text Guidelines

- Use regular strings (no need for `+` like CDN)
- Text automatically scales with component size
- Keep text concise for better readability

## Font Size

Override the default font size:

```jsx
<Placeholder 
  width="400" 
  height="200" 
  text="Large Text" 
  fontSize={48} 
/>
```

**Result:**

<Placeholder width="400" height="200" text="Large Text" fontSize={48} />

## Color Formats

### Hex Colors
- **React Format**: Standard hex format `#FF0000`
- **Example**: `color="#FF0000"`, `background="#0066CC"`

### Named Colors
- **Supported**: `white`, `black`, `red`, `blue`, `green`, `yellow`, `purple`, `orange`, `pink`, `gray`
- **Example**: `color="white"`, `background="black"`

## TypeScript Support

PlaceholderJS includes full TypeScript definitions:

```tsx
import { Placeholder } from 'placeholder';

interface PlaceholderProps {
  width: string;
  height: string;
  text?: string;
  color?: string;
  background?: string;
  fontSize?: number;
  className?: string;
  style?: React.CSSProperties;
}

function MyComponent(): JSX.Element {
  return (
    <Placeholder 
      width="300" 
      height="200" 
      text="TypeScript!" 
      color="#FFFFFF"
      background="#3B82F6"
    />
  );
}
```

## Best Practices

### Performance
- **Component Reuse**: Create wrapper components for common placeholder patterns
- **Memoization**: Use `React.memo()` for frequently rendered placeholders
- **Lazy Loading**: Consider lazy loading for off-screen placeholders

### Accessibility
- **Alt Text**: The component automatically provides appropriate alt text
- **Color Contrast**: Ensure sufficient contrast between text and background
- **Screen Readers**: Meaningful text helps screen reader users

### State Management

```jsx
function DynamicPlaceholder() {
  const [size, setSize] = useState({ width: "300", height: "200" });
  const [text, setText] = useState("Dynamic");

  return (
    <div>
      <Placeholder 
        width={size.width} 
        height={size.height} 
        text={text} 
      />
      <button onClick={() => setText("Updated!")}>
        Update Text
      </button>
    </div>
  );
}
```

## Common Patterns

### Loading States

```jsx
function ImageWithPlaceholder({ src, alt, width, height }) {
  const [loaded, setLoaded] = useState(false);

  return (
    <div style={{ position: 'relative' }}>
      {!loaded && (
        <Placeholder 
          width={width} 
          height={height} 
          text="Loading..." 
          background="#F3F4F6"
        />
      )}
      <img 
        src={src} 
        alt={alt}
        onLoad={() => setLoaded(true)}
        style={{ 
          display: loaded ? 'block' : 'none',
          width,
          height 
        }}
      />
    </div>
  );
}
```

### Responsive Placeholders

```jsx
function ResponsivePlaceholder() {
  return (
    <div className="w-full max-w-md">
      <Placeholder 
        width="100%" 
        height="200" 
        text="Responsive" 
        style={{ width: '100%', height: 'auto' }}
      />
    </div>
  );
}
```
